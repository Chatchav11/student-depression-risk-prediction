# Student Depression Risk Prediction

## Project Overview
Machine Learning project focused on predicting depression risk among university students.

---

## Dataset

**Students Mental Health Assessments**

- Source: [Kaggle Dataset](https://www.kaggle.com/datasets/sonia22222/students-mental-health-assessments)
- Records: 7,022
- Features: 20 columns

## Technologies
- Python
- Pandas
- Scikit-learn
- LightGBM

## Machine Learning Models
- Logistic Regression
- Random Forest
- LightGBM
- K-Nearest Neighbors (KNN)
- Neural Network

## Results
**Best reported accuracy: ~63.5% (LightGBM)**

---

## How to Run
Open the Jupyter Notebook and run the cells after installing the required dependencies.
