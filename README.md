# Student Depression Risk Prediction

## Project Overview
Machine Learning project focused on predicting depression risk among university students.

---

## Dataset
**Student Mental Health Survey**

## Technologies
- Python
- Pandas
- Scikit-learn
- LightGBM

## Machine Learning Models
- Logistic Regression
- Random Forest
- LightGBM
- K-Nearest Neighbors (KNN)
- Neural Network

## Results
**Best reported accuracy: ~63.5% (LightGBM)**

---

## How to Run
Open the Jupyter Notebook and run the cells after installing the required dependencies.
